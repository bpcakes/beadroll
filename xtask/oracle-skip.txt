# The tests `cargo xtask oracle` leaves out of the Python suite (docs/RUST-PORT.md §4.2): those that
# cannot target another binary, and those that run none. Derived from the catalogues in
# docs/rust-port/ and checked against a run of the fast modules through a tracing copy of the
# launcher, which recorded every test that started bead and how (test_stress and test_sweep were
# read from their source). One `GROUP TEST-ID` per line:
#
#   driver      runs the launcher itself: through runpy, under another Python, as its own copy,
#               or with sitecustomize patching inside it (20)
#   in-process  exercises the Python package in-process; no bead it starts decides the verdict (85)
#   patched     runs bead, but the verdict comes from patching in-process Python (19)
#   no-bead     runs no bead at all (11)
#
# Every other test (338) runs unchanged against whatever BEAD_UNDER_TEST names. A test that reaches
# bead some other way is fixed, not listed here. The runner refuses a list that names a test the
# suite does not have.
